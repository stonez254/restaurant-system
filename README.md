# Restaurant POS

A web-based restaurant management and point-of-sale system built with React and Vite.

## Current foundation

- Touch-friendly POS
- Dine-in, takeaway and delivery order channels
- Table status management
- Central order queue
- Kitchen Display System foundation
- Menu management with 60 sample items
- Browser persistence through localStorage
- Responsive desktop, tablet and mobile layout

## Planned modules

Inventory and recipes, ingredient batches, payments, delivery riders, customers, complaints, staff performance, expenses, COGS and profit analytics.

## Development

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```
